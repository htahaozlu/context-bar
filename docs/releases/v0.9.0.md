# ContextBar v0.9.0

Claude and Codex side by side, a context-window redesign across every screen,
reliable cross-machine sync, and a stable context meter.

## Added

- **Claude and Codex together.** Stats and Cost gain a **Both** filter (the new
  default) that merges both agents, and the popover shows a card for each active
  agent at once instead of only the most-recently-used one.
- **Session context detail.** Click a session in the popover (or the hero card)
  to see its context-window fill (used / free / %), token composition, and an
  estimated per-turn "context loaded" breakdown — CLAUDE.md, MCP instructions and
  skills, read from the transcript. Claude's full `/context` category split lives
  only inside Claude Code and is never written to disk, so the loader sizes are
  marked as estimates.
- **Reliable iCloud sync.** Peer Macs' rollup files are force-downloaded from
  iCloud Drive (placeholders included), so office/home machines actually appear
  under Cost → "Across your Macs". Turn on iCloud Drive sync in Settings on each
  Mac (same Apple ID).
- **Appearance override at launch.** Settings → Appearance → Theme
  (System / Light / Dark) is applied on launch, not only when Settings opens.

## Changed

- **macOS UI matches the design system end to end** — popover, Stats, Cost and
  Settings rebuilt with pill filter buttons, rounded popups, pill switches,
  glyph wells and hairlines; two-column Stats/Cost grids, a model filter and
  metric tiles; a centered Settings column with grouped cards. Existing features
  (drill-downs, AI advisor, cross-machine sync, heatmap) are preserved.
- Menubar idle text renders full-strength instead of dim gray.

## Fixed

- **Context % no longer reads above 100% or jumps.** Current Claude models
  (Opus / Sonnet 4.8) are recognized as 1M-context, the window no longer flips
  200k↔1M at the boundary, and the menubar percentage comes from the foreground
  active session — excluding sub-agent transcripts whose large cache reads
  previously inflated it.
