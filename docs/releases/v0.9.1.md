# ContextBar v0.9.1

Refinements to the 0.9.0 redesign: git-aware project labels, separate Privacy
and About tabs, a cleaner menubar popover, and a UI/UX alignment pass.

## Added

- **Privacy and About are their own tabs.** The detail window is now five tabs —
  Stats · Cost · Settings · Privacy · About — rather than bundling
  General/Privacy/About into one Settings scroll.

## Changed

- **Project label follows the git repo, not the sub-directory.** A session deep
  inside a repository (or a git worktree) shows the repo name (origin remote,
  else the repo root folder) instead of whatever sub-folder it started in.
  Non-git directories show `parent/leaf` (e.g. `hususi/backend`) so they read as
  a location rather than a fake project name.
- **Cleaner popover.** Active-session hero on top, parallel sessions beneath it,
  and two limit cards at the bottom (Claude and Codex) — no more two stacked
  hero cards.
- **UI/UX pass on Stats, Cost and Settings.** Top-aligned, equal-height cards and
  tiles in the two-column grids (no more shifted/misaligned cards), consistent
  spacing, and the secondary tools grouped below a divider so the core view is
  less cluttered.
