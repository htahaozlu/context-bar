# ContextBar v0.7.3

Sharper Stats drill-down, an honest "active session" state, and the menubar
popover tightened the rest of the way.

## Added

- **Per-day session list** — pick a day (or click a heatmap cell) and see that
  day's sessions: start time, duration, model · project, tokens · cost.
- **Codex reasoning-effort tile** — Stats surfaces the most-used effort
  (`X-High`/`High`/…) when Codex transcripts record one. Claude has no effort
  field, so the tile shows only for Codex.

## Changed

- **About is its own tab again** (Usage · Stats · Value · General · Privacy ·
  About) so the update controls live on their own.
- **Native date picker** — the breakdown's date field is now a compact pill that
  opens the native macOS calendar (single day or range) instead of a flat field.
- **Correct model labels** — `claude-opus-4-8` reads "Opus 4.8" (was "Opus 4");
  added 4.9 / Sonnet 4.7 / GPT-5.5.

## Fixed

- **Stale "active session."** Past the 30-minute activity window an idle session
  no longer reads as live: the dot greys, context % blanks, and the card shows
  "last active …" instead of a fake running duration — so a refresh on an idle
  machine no longer looks like it did nothing.
- **Menubar popover top/right dead space** — tightened from a 20pt uniform outer
  gutter to a 4pt vertical inset + 8pt horizontal card gutter.
