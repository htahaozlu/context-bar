# ContextBar v0.7.6

Per-session Context drill-down and a per-machine usage breakdown.

## Added

- **Click a session → its Context composition.** Session rows in the Stats
  daily breakdown are now clickable. Each opens a popover with that session's
  honest token composition — Input / Output / Cache-write / Cache-read with
  counts and %, plus total context tokens handled. Cache-read is the context
  re-sent every turn (system prompt + tools + history).

  Note: Claude's live `/context` per-component split (system prompt vs tools vs
  MCP vs messages) is not recorded per past session anywhere on disk, so it is
  deliberately **not fabricated** — the categories shown are measured, not
  guessed.

- **Per-machine breakdown in "Across your Macs" (Value tab).** Each Mac now
  appears as a bar (This Mac first) with its 30-day tokens + estimated cost and
  a combined total — "which computer used how much." Account-wide 5h/7d rolling
  limits stay on the Usage tab (already cross-machine); this section is the
  per-machine local cost rollup synced through your shared folder.
