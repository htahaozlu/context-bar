# ContextBar v0.10.0

A cost-accuracy correction plus four UI fixes. The headline: the API-equivalent
cost figures were overstated (roughly 2×) and are now correct — verified against
Anthropic's official pricing and cross-checked with ccusage.

## Fixed — cost accuracy

- **Repeated turns are no longer double-counted.** Claude Code copies prior turns
  into resumed-session files and replays sidechain turns, so the same billed API
  response appeared many times across transcripts — about half of all logged
  turns were duplicates. We now count each `(message.id, requestId)` once, the
  same key ccusage uses. On real data this roughly halves the 30-day figure.
- **1-hour cache writes priced correctly.** Anthropic bills a 1-hour prompt-cache
  write at **2× input**, not the 5-minute rate (1.25×). We now read the
  `ephemeral_5m` / `ephemeral_1h` split and price each bucket correctly. The 1h
  bucket is the majority of cache creation in practice, so this matters.
- **The net effect:** the displayed 30-day API-equivalent cost was ~2.3× too high
  and is now correct. It's still an estimate of what the metered API would charge
  (subscription users aren't billed per token) — the UI says so plainly.

## Added

- **Fable 5 pricing** ($10 / $50 per Mtok, 5m cache $12.50, read $1.00). Fable 5
  usage was previously priced at $0.

## Fixed — UI

- **Theme setting is findable again.** The accent-palette picker is now labelled
  "Theme / Tema"; the System / Light / Dark switch is "Mode / Mod" (a recent
  rename had put "Tema" on the Light/Dark switch and hidden the palette under
  "Accent / Vurgu").
- **The Cost tab no longer jumps.** Switching into Cost used to abruptly grow the
  window; every tab now shares one window size and taller content scrolls.
- **The activity breakdown sits under the graph.** Clicking a day in the
  contribution heatmap updates the per-day detail directly beneath it (and scrolls
  it into view) instead of changing a panel buried far below.
- **Subscription users see "plan", not "API".** The per-model plan/API label now
  follows the detected account: with an active Claude subscription every Claude
  model reads as plan-covered; only genuinely uncovered providers (Codex / GPT)
  read as API-billed.
