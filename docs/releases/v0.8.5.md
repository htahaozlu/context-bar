# ContextBar v0.8.5

Git-aware project labels, iCloud Drive sync, and another pass on the macOS app polish.

## Changed

- **Project names now show the real repo.** When an agent starts in a nested
  folder, ContextBar now walks up to the nearest git repo and prefers the
  repository name from `origin` (or the repo root folder) instead of showing the
  leaf working directory.
- **Across your Macs now starts with iCloud Drive.** The Privacy pane adds a
  zero-config iCloud Drive sync option for Macs on the same Apple ID, while
  keeping the self-hosted server and manual synced-folder paths available.
- **JetBrains Mono is bundled into the app.** Release and local menubar builds
  now ship the font assets directly, so the numeric UI stays visually
  consistent.
- **Popover and settings polish continues.** The current macOS UI pass refines
  spacing, hierarchy, and component treatment across the clay-themed surfaces.

## Fixed

- **Menubar context meter source mismatch.** In some sessions the app could
  fall back to a fresh context percentage from `active_sessions` while still
  showing an older top-level context-window size. That produced impossible
  combinations like roughly `200k` tokens reading as about `70% of 1M`. The
  parser now resolves the percentage and the window from the same source, so
  the `%` and `used / window` displays stay in sync.
