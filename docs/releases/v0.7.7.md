# ContextBar v0.7.7

Clearer per-session Context, and an honest account-wide + per-machine usage view.

## Changed

- **Per-session Context popover, made legible.** The old four-way "context
  tokens handled" split read as noise. It now leads with **estimated cost +
  fresh tokens**, shows a simple **Input / Output** "fresh work" bar, and states
  the replayed conversation as one plain line — `↻ N cached context replayed
  (≈M×)` — with a short explanation.

  Researched with Codex first: Claude Code's `/context` per-component breakdown
  (system prompt / tools / MCP / messages) is computed **live, inside Claude
  Code**, and is not persisted anywhere a separate app can read — verified
  against transcripts, statusline JSON, OTel, and tools like ccusage. So the
  categories shown are **measured, never fabricated**.

- **"Across your Macs" is now two honest planes.**
  - **Account · all machines · live** — the rolling 5h/7d limits, which already
    count every machine in real time via the account usage API (no shared folder
    needed). This is the real "account overall" view.
  - **Per machine · local 30-day** — optional, via a folder you already sync,
    since the account API can't break token/cost down by machine.
