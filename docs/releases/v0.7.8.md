# ContextBar v0.7.8

Paste into the API-key field, and a tidier Privacy pane.

## Fixed

- **The AI API-key field wouldn't accept a paste** — you could only type into
  it. As a menubar (accessory) app with no Edit menu, the standard
  ⌘X/⌘C/⌘V/⌘A shortcuts were never delivered to text fields. A standard Edit
  menu is now installed, so the key field — and every text field — accepts
  paste.

## Changed

- **Privacy pane reordered.** AI Advisor (bring your own key) is now at the top,
  and the redaction "Preview" sample section was removed.
