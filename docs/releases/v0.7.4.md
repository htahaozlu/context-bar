# ContextBar v0.7.4

A fix so the per-day session list actually populates.

## Fixed

- **Per-day session list stayed empty.** Session start times carry microsecond
  precision (`…:24.188000Z`), which `ISO8601DateFormatter` won't parse (it only
  accepts 3 fractional digits) — so no session ever matched the selected day.
  The parser now strips sub-seconds and retries, so selecting a day (or clicking
  a heatmap cell) in the Stats breakdown lists that day's sessions: start time,
  duration, model · project, tokens · cost.
